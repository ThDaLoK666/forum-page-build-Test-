🚀 Task 1: ค้นหาคำถามและคลังไฟล์ถาวร (Search Questions & Assets) 

เป้าหมายผู้ใช้: ต้องการหาทางแก้ปัญหาจากคำถามเก่า หรือดาวน์โหลดไฟล์วิชาที่ต้องการบนหน้า Feed รวม โดยไม่ต้องกลัวข้อมูลไหลหาย 

ขั้นตอนการทำงานบน UI (Flow ตั้งแต่ต้นจนจบ): 

สืบค้นปัญหา: พิมพ์คีย์เวิร์ดในแถบค้นหาอัจฉริยะ Keyword Search & Tag Cloud ด้านบนสุด หรือคลิกปุ่มแฮชแท็กวิชา/หัวข้อ (เช่น #ITCS212, #Java) บนการ์ดคำถามที่เห็น -> UI แสดงรายการคำถามทั้งหมดที่ตรงกับแท็กหรือคำค้นหาขึ้นมาบนฟีดหลัก 

ดาวน์โหลดไฟล์อ้างอิง: มองไปที่กล่องคลังความรู้ปักหมุด Pinned Academic Repository ด้านบนสุดของหน้าผลการค้นหา แล้วคลิกปุ่ม [Download] บนการ์ดไฟล์ที่แสดงป้าย • No expiry -> UI ดำเนินการดาวน์โหลดไฟล์ประกอบการเรียนลงเครื่อง 

ผลลัพธ์บน UI หลังทำเสร็จ: ผู้ใช้ได้ไฟล์เรียนหรือเจอกระทู้คำถามเก่าที่ตรงกับวิชาหรือหัวข้อที่กำลังตามหาทันที โดยไม่ต้องเลื่อนหาในแชทให้ข้อมูลไหลหาย 


📝 Task 2: ร่าง ตั้งคำถาม และส่งโพสต์นิรนาม (Ask Question & Publish Anonymously) 

เป้าหมายผู้ใช้: ต้องการตั้งคำถามใหม่ แปะโค้ดและรูป Error ตรวจเช็คความปลอดภัย แล้วส่งขึ้นบอร์ดโดยไม่เปิดเผยตัวตนจริง 

ขั้นตอนการทำงานบน UI (Flow ตั้งแต่ต้นจนจบ): 

เปิดหน้าตั้งคำถาม: คลิกปุ่ม [+ New Post] (หรือ Ask Question) ที่มุมบนขวาของหน้าจอหลัก -> UI เปิดหน้าต่าง/หน้าเว็บร่างคำถามใหม่ที่แบ่งเป็นฝั่งพิมพ์ (ซ้าย) และฝั่งตัวอย่างพรีวิว Live Preview Sandbox (ขวา) 

พิมพ์อธิบายและติดแท็ก: พิมพ์ชื่อคำถาม พิมพ์อธิบายรายละเอียด และพิมพ์ระบุแท็กวิชา/หัวข้อ (เช่น #ITCS212, #Java) ในช่องพิมพ์ -> UI แสดงแท็กที่เลือกเป็นป้ายกำกับชัดเจน 

วางโค้ดและแนบรูป Error: วางซอร์สโค้ดในกล่อง Dedicated Code Snippet Block และกดแนบรูปภาพ Log Error -> UI จัดฟอร์แมตโค้ดแสดงเลขบรรทัด แยกสี Syntax และเรนเดอร์ภาพ Error ต่อท้ายในกล่องเดียวกันแบบ Inline 

สลับโหมดซ่อนตัวตน: คลิกเปิดสวิตช์ Anonymity Masking Toggle (Post as Anonymous) -> UI เปลี่ยนสถานะปุ่มสวิตช์เป็นเปิดใช้งาน 

ตรวจทานและกดส่งโพสต์: มองฝั่ง Live Preview Sandbox ขวามือเพื่อเช็คความเรียบร้อยของโค้ด และดูตราสัญลักษณ์สีเขียว ✓ Pre-Publishing Audit: Safe ที่ยืนยันว่าชื่อจริงถูกสลับเป็นชื่อนิรนาม (เช่น Anonymous Student #12) แล้วจริง ๆ จากนั้นคลิกปุ่ม [Publish Post] -> UI ปิดหน้าร่างโพสต์ลง 

ผลลัพธ์บน UI หลังทำเสร็จ: หน้าจอพาผู้ใช้ไปยังหน้ารายละเอียดคำถามที่เพิ่งสร้างเสร็จทันที โดยคำถามจะแสดงผลแบบบอร์ดกระทู้ทิ้งไว้ (Asynchronous Board Design) และซ่อนชื่อจริงผู้โพสต์ถาวร 


💬 Task 3: ดีบั๊กร่วมกันในคอมเมนต์ย่อย และส่งคำตอบหลักเพื่อโหวตคะแนน (Interact, Solve & Rate Answers) 

เป้าหมายผู้ใช้: ต้องการช่วยเพื่อนวิเคราะห์โค้ด พิมพ์ถามข้อมูลเพิ่ม ส่งคำตอบหลักที่เป็นวิธีแก้ไข และช่วยกันโหวตคัดกรองเนื้อหา 

ขั้นตอนการทำงานบน UI (Flow ตั้งแต่ต้นจนจบ): 

เข้าสู่หน้ารายละเอียดคำถาม: คลิกเลือกกล่องคำถามบนหน้าแรกเพื่อเปิดอ่านคำถาม โค้ด และรูป Error อย่างละเอียด -> UI แสดงหน้ารายละเอียดคำถามเดี่ยว (Question Detail View) 

พิมพ์ถาม-ตอบข้อสงสัยย่อย: พิมพ์ข้อความซักถามประเด็นเพิ่มเติมในกล่องคอมเมนต์ย่อยใต้คำถามหลัก -> UI แสดงแถบสนทนาโต้ตอบแบบเยื้องขอบซ้าย (Clarification Nested-Comment Line) เชื่อมโยงเป็นเส้นแนวตั้ง เพื่อแยกพื้นที่คุยรายละเอียดไม่ให้ไปรกพื้นที่คำตอบหลัก 

เขียนคำตอบหลักเพื่อแก้ปัญหา: พิมพ์คำอธิบายวิธีแก้ไขพร้อมวางโค้ดชุดใหม่ในช่อง Primary Solution Input Box ด้านล่างสุดของหน้าจอแล้วกดส่ง -> UI สร้างกล่อง "คำตอบ (Answer)" ขนาดใหญ่แยกสัดส่วนชัดเจน 

โหวตคุณภาพคำตอบ: คลิกปุ่มลูกศรชี้ขึ้น (Upvote) หรือชี้ลง (Downvote) บนแผง Peer Rating Interface ด้านซ้ายของกล่องคำตอบ -> UI อัปเดตคะแนนโหวตให้เห็นเรียลไทม์ และระบบจะสลับเอาคำตอบที่ได้คะแนนโหวตจากเพื่อน ๆ สูงสุดขึ้นมาแสดงผลด้านบนสุดอัตโนมัติ 

ผลลัพธ์บน UI หลังทำเสร็จ: เกิดหน้าประเด็นคำถามที่มีข้อมูลคุยย่อยเป็นสัดส่วนชัดเจน และคำตอบที่เพื่อน ๆ ช่วยกันโหวตว่าดีที่สุดจะถูกดันขึ้นมาให้คนอื่นเห็นก่อนทันที 


🛡️ Task 4: ตรวจสอบและยืนยันความถูกต้องของคำตอบ (Verify & Lock Answer) 

เป้าหมายผู้ใช้: (สำหรับอาจารย์/TA) ต้องการรับรองคำตอบที่ถูกต้อง / (สำหรับนักศึกษาทั่วไป) ต้องการเข้ามาเอาคำตอบที่เชื่อถือได้ไปใช้อย่างมั่นใจ 

ขั้นตอนการทำงานบน UI (Flow ตั้งแต่ต้นจนจบ): 

กดรับรองคำตอบ (สิทธิ์ผู้สอน): อาจารย์หรือ TA เปิดเข้ามาที่กล่องคำตอบที่ถูกต้อง แล้วคลิกปุ่ม [✓ Verify This Answer] ที่มุมขวาบน -> UI ล็อกคำตอบนั้นแล้วดึงขึ้นไปปักหมุดไว้บนสุดใต้คำถามทันที (Pin to Top) 

เช็คตราความถูกต้องและอ่านโน้ต: นักศึกษาเปิดกระทู้นี้เข้ามาเพื่อหาคำตอบ แล้วสังเกตเห็นตราติ๊กถูกสีเขียว ✓ Verified Answer บนกล่องคำตอบแรกสุด พร้อมอ่านโน้ตข้อพึงระวังเพิ่มเติมจากอาจารย์ -> UI ไฮไลต์กล่องโน้ตของอาจารย์ด้วยสีที่เด่นชัด 

คัดลอกโค้ดไปใช้งาน: ลากเมาส์คลุมหรือกดปุ่มคัดลอกซอร์สโค้ดในกล่องที่ได้รับการ Verified ไปใช้งาน -> UI แสดงกล่องแจ้งเตือนสั้น ๆ (Toast Notification) เด้งมุมจอระบุว่าคัดลอกสำเร็จ 

ดูเนื้อหาแนะนำเสริมข้างจอ: สังเกตและคลิกเปิดลิงก์บนกล่อง Recommendation Widget ด้านข้างจอหลัก -> UI แสดงเนื้อหา/สไลด์/คลิปเรียนทบทวนเพิ่มเติมที่ระบบดึงมาให้ล้อตามแฮชแท็กปัญหาที่เด็ก ๆ กำลังติดบั๊กกันอยู่ 

ผลลัพธ์บน UI หลังทำเสร็จ: นักศึกษาได้โค้ดและวิธีคิดที่ผ่านการการันตีจากผู้สอน (Single Source of Truth) ไปใช้อ่านสอบหรือส่งงานต่อได้อย่างมั่นใจ 100% 


🔥 Task ส่วนขยายพิเศษ: ตัวกรองช่วงวิกฤตใกล้สอบ (Panic Period Filter) 

เป้าหมายผู้ใช้: ต้องการเก็งประเด็นเร่งด่วนเพื่อดูว่าเพื่อน ๆ ส่วนใหญ่ติดปัญหาเรื่องอะไรกันมากที่สุดในช่วง 1 สัปดาห์ก่อนสอบ 

ขั้นตอนการทำงานบน UI: 

คลิกปุ่มรูปไฟสีส้มแดง [🔥 Panic Period Filter Button] ที่อยู่ใต้แถบค้นหาหลักบนหน้าแรก -> UI สลับธีมสีหน้าจอเล็กน้อย และรีเฟรชหน้าฟีดรวมเพื่อดึงเฉพาะกระทู้ที่มีจำนวนการเข้าดู (Views) หรือการตอบโต้ (Engagement) สูงสุดในรอบ 7 วันล่าสุดขึ้นมาเรียงให้ดูทันที 

ผลลัพธ์บน UI หลังทำเสร็จ: หน้าฟีดแสดงเฉพาะกระทู้ประเด็นร้อนก่อนสอบ ช่วยให้ผู้ใช้เก็งหัวข้อสำคัญได้ทันทีในคลิกเดียว
