## ก่อนอัด
1. เปิด Chrome แบบ **Incognito** หน้าต่างใหม่ (localStorage ว่าง ภาพสะอาด) ซูม 100% เต็มจอ ปิดแจ้งเตือน/แท็บอื่น
2. เปิดเว็บแล้ว **ซ้อมเดินตามตาราง 1–2 รอบ** (โพสต์ที่สร้างตอนซ้อมจะหายเมื่อปิด Incognito)
3. **ห้ามกด:** ปุ่ม Test UI มุมขวาล่าง, แท็บ Study Session, ป้าย Verified, Join Session (เป็น Future Work)
4. **ห้ามกดคำแนะนำ (suggestion) ของช่องค้นหา ยกเว้นข้อ 9** และห้ามเปิดกระทู้ "Java exceptions" / "3NF" ในฟีด → ขึ้น "Question not found" (ข้อมูลกระทู้รหัส 3–8 ไม่มีในโค้ด) กระทู้ที่เปิดได้: รหัส 1 (Binary Search Tree), 2 (SQL JOIN types)
5. ช่องค้นหากรองทันทีขณะพิมพ์ **ไม่ต้องกด Enter**
6. ตอนกรอกฟอร์ม **อย่าพิมพ์ข้อมูลส่วนตัว** (อีเมล เบอร์โทร รหัสนักศึกษา) ระบบมี Pre-Publishing Audit บล็อกการโพสต์ จะกดโพสต์ไม่ได้
7. **อย่าชี้/เน้น** ส่วนที่สไลด์ 38 ระบุเป็น Future Work: แผง Pre-Publishing Audit (ตรวจข้อมูลส่วนตัวอัตโนมัติ), แผง Recommended for you, ป้าย Solved/Verified, การแนบไฟล์/รูป/วิดีโอ ถ้าติดอยู่ในภาพ ไม่ต้องพูดถึง
8. เมาส์เคลื่อนช้าๆ หยุดแต่ละจุดตามเวลา "ค้าง" อย่าลากเมาส์พล่าน

## สคริปต์พูด + จุดหยุด

**P0 ก่อนกดเล่น (~25 วิ) — บอกวิธีทดสอบ**
"ก่อนดูวิดีโอ ขอเล่าว่าเราทดสอบอย่างไรครับ ผู้ทดสอบ 3 คน P1 เป็นกลุ่มเป้าหมายจริง P2 กับ P3 เป็นผู้ทดสอบภายนอกเสริม ผมอ่านให้ฟังเฉพาะสถานการณ์ ไม่บอกชื่อปุ่ม จับเวลา และบันทึกว่าต้องช่วยหรือไม่ A0 ถึง A3 หลังเสร็จให้คะแนนความง่าย 1 ถึง 7 วิดีโอนี้เดินตามสองภารกิจที่ใช้ทดสอบจริง"

**ช่วงเล่นช็อต 1–2 (0:00–0:20)** พูดสั้นๆ ขณะเล่น: "ภารกิจแรก หาเอกสารและกระทู้เก่าของวิชา ITCS210 ผู้ทดสอบเลือกวิธีหาเอง"

**★ P1 หยุดที่ 0:20 (~25 วิ) — T1 เส้นทางของผู้ทดสอบ**
"แต่ละคนหาไม่เหมือนกันครับ P2 พิมพ์คำค้นเจาะจง บอกว่า 'ผมพิมพ์เจาะๆ ไปเลยดีกว่า' ส่วน P3 กดแท็กเลย บอกว่า 'ผมกดแท็กเอาเลยดีกว่า เร็วกว่าพิมพ์' ไม่มีใครเดินผิดทางหรือย้อนกลับ แล้วไฟล์ปักหมุดของวิชาก็ขึ้นเอง" → กดเล่นต่อ

**ช่วงเล่นช็อต 3–4 (0:20–0:42)** ไม่ต้องพูด (ปล่อยให้ดู)

**★ P2 หยุดที่ 0:42 (~25 วิ) — T1 ผล**

**ช่วงเล่นช็อต 5–6 (0:42–1:05)** พูดขณะเล่น: "นอกจากการค้นหา เว็บมีหน้ากระทู้แบบมีโครงสร้าง มีแท็กวิชา และช่องตอบ" (ถ้าไม่แน่ใจ ข้ามไปเลย) จากนั้น: "ภารกิจที่สอง ติด Error ตอนเที่ยงคืน อยากถามแต่ไม่อยากให้ใครรู้ว่าเป็นเรา"

**ช่วงเล่นช็อต 7 (1:05–1:35)** พูดสั้นๆ: "ผู้ทดสอบเลือกวิชา แท็ก เขียนคำถามและวางโค้ดในกล่องโค้ด"
