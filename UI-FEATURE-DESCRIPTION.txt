รายละเอียด Component ที่ใช้ร่วมกัน (Reusable Components)
================================================================================

  1. VoteButton
     - ปุ่มโหวตแนวตั้ง (Up/Down)
     - แสดงตัวเลข counter ตรงกลาง
     - toggle state (กดซ้ำเพื่อยกเลิก)

  2. NestedReply
     - คอมโพเนนต์ recursively render ความคิดเห็นแบบซ้อน
     - depth tracking สำหรับ indentation
     - เส้นเชื่อมแนวตั้ง (left border line)
     - role-based avatar colors
     - collapsible sub-replies
     - รองรับ Code Block และ Image upload ใน reply

  3. AnswerCard
     - แสดงคำตอบแต่ละข้อ
     - เส้นขอบซ้ายสีตามสถานะ
     - badge ยืนยัน
     - vote buttons
     - comments section
     - ปุ่ม Delete (เฉพาะ owner), Copy Code, Image paste

  4. QuestionCard
     - การ์ดคำถามในหน้า feed
     - badge สถานะ solved/verified
     - แท็ก + metadata
     - คลิกได้ นำไปหน้า Thread Detail

  5. FilterTabs
     - แถบ pill/capsule เลื่อนแนวนอน (scrollable)
     - ใช้บน Community Dashboard: All + Panic Period
     - Panic Period มี style พิเศษ (gradient สีแดง + animate-pulse)

  6. TagClouds
     - คลัสเตอร์แท็กแบบ capsule
     - multi-select + clear
     - แสดงแท็กที่เลือกแล้ว + ปุ่มลบ (✕)
     - 18 แท็กบน Community Dashboard

  7. PinnedRepository
     - กล่องปักหมุดไฟล์วิชาการ
     - แสดง 6 ไฟล์ (PDF, DOCX, PPTX)
     - ปุ่ม Download ที่ด้านขวาของแต่ละไฟล์
     - รองรับ download progress modal

  8. QuestionCreator
     - Centered modal (max-w-7xl, full-width on mobile)
     - Split-pane layout (editor + preview)
     - PII detection audit (Pre-Publishing Audit)
     - Tag selection (18 แท็ก แบบ multi-select)
     - canSubmit validation: title && subject && auditPassed

  9. Sidebar
     - รวม My Subjects + Tag Cloud + Pinned Academic Assets
     - กดเลือกวิชาเพื่อกรองคำถาม
     - เลือกแท็กหลายตัวพร้อมกัน
     - แสดงไฟล์ปักหมุดพร้อมปุ่ม Download

  10. Recommendation Widget
      - แสดงใน Thread Detail page (sidebar ขวา เฉพาะ Desktop)
      - เนื้อหาที่เกี่ยวข้องตามแท็กของคำถาม
      - 3 ประเภท: Slides, Video, Notes
      - Sticky position (ติดด้านบนเมื่อ scroll)
